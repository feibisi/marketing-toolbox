字体系统 Typography System

字体系统基于1.25x (大三度音程) 比例,确保视觉层次清晰。

--font-size-4xl (35.2px)
A3画布主标题 (H1)
--font-size-3xl (27.2px)
A4画布主标题 (H1)
--font-size-2xl (24px)
二级标题 (H2)
--font-size-xl (20px)
三级标题 (H3) / 卡片标题
--font-size-base (14.4px)
基准字号 - 正文、输入框、按钮
--font-size-sm (12px)
小号文字 - 标签、辅助文字
--font-size-xs (10.4px)
微型文字 - 角标、超小说明

组件库 Component Library

可复用的UI组件,可直接复制代码使用。

按钮 (Buttons)

<button class="btn btn-secondary">次要按钮</button>
<button class="btn btn-ghost">轻量按钮</button>

输入框 (Inputs)
