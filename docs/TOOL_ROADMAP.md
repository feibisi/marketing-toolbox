# Modiqi Tool Roadmap & Gap Analysis (Comprehensive Edition)

## 1. Roadmap Overview
This expanded roadmap defines the full "Consulting Operating System" scope. It aims to cover every major touchpoint in a digital consultancy engagement, from initial audit to final reporting.

> **Note**: Tools marked with "✨" are high-priority "Hero Tools" with complex interactivity.

---

## 2. Workbench Expansion Plan (Deep Dive)

### 🚀 Strategy Workbench (The "War Room")
**Theme**: High-level decision making and organizational alignment.

1.  **OKR / KPI Cascade Map** ✨
    *   *Function*: Visual pyramid connecting Vision -> Objectives -> Key Results -> Initiatives.
    *   *Logic*: Auto-calculates "Confidence Score" (0-100%) for each level based on child items.
2.  **Risk Assessment Matrix (RAID Log)**
    *   *Function*: Categorize Risks, Assumptions, Issues, Dependencies.
    *   *Interaction*: Drag-and-drop bubbles onto a Probability vs. Impact grid.
3.  **Change Management Canvas**
    *   *Function*: Plan organizational transformation (ADKAR model).
    *   *Structure*: Awareness -> Desire -> Knowledge -> Ability -> Reinforcement.
4.  **Stakeholder Mapping Radar**
    *   *Function*: Plot stakeholders by Influence vs. Interest.
    *   *Visual*: Concentric circles (Team, Company, External) with quadrants.
5.  **Blue Ocean Strategy Canvas**
    *   *Function*: Compare value curves against competitors.
    *   *Interaction*: Draggable line chart points to create "As-Is" vs "To-Be" curves.

### 🎨 Brand Workbench (The "Studio")
**Theme**: Identity, Voice, and Storytelling.

1.  **Brand Archetype Wheel** ✨
    *   *Function*: Interactive 12-slice wheel to select primary/secondary archetypes.
    *   *Logic*: Selecting "Sage" auto-populates "Truth-seeking", "Expertise" keywords.
2.  **Naming Brainstorm Matrix**
    *   *Function*: Structured ideation for brand names.
    *   *Grid*: Descriptive, Associative, Abstract, Acronyms, Composite.
3.  **Tone of Voice Equalizer**
    *   *Function*: 5-slider inputs (Funny-Serious, Formal-Casual, etc.).
    *   *Output*: Generates a dynamic "Voice Statement" sentence based on slider positions.
4.  **Brand Touchpoint Map**
    *   *Function*: Audit brand consistency across Pre-purchase, Purchase, and Post-purchase.
    *   *Interaction*: "Traffic Light" rating (Green/Yellow/Red) for each touchpoint.
5.  **Visual Style Tile Generator**
    *   *Function*: "Moodboard Lite" for consultants.
    *   *Input*: Upload Logo, defined Colors, Font Names.
    *   *Output*: Clean, A4 layout summarizing the visual identity.

### 💼 Sales Workbench (The "Closer")
**Theme**: Pipeline velocity and deal intelligence.

1.  **Sales Script Flowchart Builder** ✨
    *   *Function*: Visual node-based editor for call scripts.
    *   *Structure*: Start -> Gatekeeper -> Value Prop -> Objection -> Close.
    *   *Print*: Linearing the flow into a readable checklist.
2.  **MEDDIC Qualification Scorecard**
    *   *Function*: Enterprise deal grading.
    *   *Logic*: Checkbox score calculating "Win Probability". Visual warning if "Economic Buyer" is missing.
3.  **Pricing Tier Architect**
    *   *Function*: Design Good/Better/Best pricing tables.
    *   *Logic*: "Decoy Effect" highlight – helps consultants show clients how to steer buyers.
4.  **Stakeholder Buy-in Heatmap**
    *   *Function*: Org chart overlay showing Supporter/Detractor status.
    *   *Visual*: Green/Red halo effects on stakeholder cards.
5.  **Contract Negotiation Planner**
    *   *Function*: Define "Give/Get" variables (e.g., "If they ask for discount, we ask for longer term").

### 📢 Social & Content Workbench (The "Newsroom")
**Theme**: Content production and channel management.

1.  **Content Repurposing Waterfall** ✨
    *   *Function*: Plan how 1 Core Asset turns into 10 Micro-assets.
    *   *Structure*: Core Video -> Blog -> Tweet Thread -> LinkedIn Carousel -> Reel.
2.  **Influencer Audit Card**
    *   *Function*: Evaluate potential KOLs.
    *   *Metrics*: Engagement Rate Calculator (Inputs: Followers, Likes, Comments).
3.  **Crisis Response Playbook**
    *   *Function*: Decision tree for handling negative PR.
    *   *Logic*: Triage severity levels (Green/Yellow/Red) -> Auto-suggested response tone.
4.  **Campaign Timeline (Gantt)**
    *   *Function*: 3-month view of Tease -> Launch -> Sustain phases.
    *   *Interaction*: Draggable timelines for different channels.
5.  **Topic Cluster Mapper**
    *   *Function*: SEO/Content strategy visualizer.
    *   *Visual*: Central "Pillar Page" node connected to satellite "Support Article" nodes.

### � Analytics Workbench (The "Lab")
**Theme**: Measurement, attribution, and data storytelling.

1.  **Measurement Plan Builder** ✨
    *   *Function*: Business Goal -> KPI -> Metric -> Dimension hierarchy.
    *   *Output*: Spec sheet for GA4/Tag Manager implementation.
2.  **Data Storytelling Canvas**
    *   *Function*: Structured report layout: "What happened?" -> "Why?" -> "So What?" -> "Now What?".
3.  **Attribution Model Comparator**
    *   *Function*: Visual explainer of attribution models (First Click vs Linear vs Decay).
    *   *Purpose*: Educational tool for consultants to explain concepts to clients.
4.  **UTM Builder & Tracker**
    *   *Function*: Form to generate valid UTM URLs.
    *   *Logic*: Auto-saves generated URLs to a local list for record keeping.
5.  **Hypothesis Prioritization (ICE)**
    *   *Function*: Rank growth experiments.
    *   *Logic*: (Impact x Confidence x Ease) formula = Score.

### 🤖 AI Workbench (The "Future")
**Theme**: AI adoption and prompt engineering.

1.  **Prompt Engineering Canvas** ✨
    *   *Function*: Structured framework for complex prompts (CO-STAR method).
    *   *Fields*: Context, Objective, Style, Tone, Audience, Response format.
2.  **AI Opportunity Radar**
    *   *Function*: Assess business functions for AI automation potential.
    *   *Categories*: Content, Code, Data, Support, Admin.
3.  **LLM Risk Assessment**
    *   *Function*: Compliance checklist for AI deployment.
    *   *Checks*: Privacy, Hallucination, Bias, IP ownership.
4.  **AI Tool Selection Matrix**
    *   *Function*: Compare tools (ChatGPT vs Claude vs Midjourney) per use case.

### 🔍 Search Workbench (SEO/SEM)
**Theme**: Visibility and technical health.

1.  **Technical SEO Audit Traffic Light**
    *   *Function*: check-list for Core Web Vitals, Mobile, HTTPS.
    *   *Visual*: Big Green/Red status indicators suitable for executive summaries.
2.  **Keyword Intent Mapper**
    *   *Function*: Map keywords to User Journey Stage (Awareness -> Consideration -> Decision).
3.  **Ad Copy A/B Test Previewer**
    *   *Function*: Mockup Google Ads SERP preview.
    *   *Limits*: Character counting enforcement (30 chars headline, 90 chars desc).

## 4. Functional Detail: "Hero Tool" Interaction Models

**Example: Sales Script Flowchart Builder**
*   **Input**: User clicks "+" to add a "Node".
*   **Node Types**: "My Speech", "Client Response (Yes)", "Client Response (No)".
*   **Canvas**: Vertical scrolling "chat-like" or "tree" view.
*   **Print Mode**: Flattens the tree into a numbered outline: "1. Intro... 2. If they say Yes go to 3..."

**Example: Brand Archetype Wheel**
*   **UI**: CSS-based Pie Chart with 12 clickable slices.
*   **State**: Active slice expands.
*   **Content**: "Helper text" sidebar updates instantly with the description of the selected Archetype.
*   **Print Mode**: Highlights the selected wedge, greys out others, and prints the full detail text below.
