# Marketing Toolbox 设计宪法

> 状态：产品与界面的最高设计约束。若旧设计文档、页面补丁或质量指标与本文冲突，以本文为准；例外必须记录设计决策。

## 1. 产品隐喻

Marketing Toolbox 是一张数字工作台，不是由 144 个普通网页表单组成的目录。用户在工作台上完成思考，并取得可以保存、复核和打印的成果。

纸张是成果载体，不是装饰背景。工具栏、证据登记、工作流状态、导入导出和帮助属于工作台，不属于纸张正文。

## 2. 四类工具

| 类型 | 定义 | 屏幕呈现 | 输出 |
| --- | --- | --- | --- |
| `fixed-canvas` | 矩阵、地图和需要整体构图的画布 | 桌面保持固定 A3/A4 比例 | 原则上单张纸 |
| `worksheet` | 清单、分步规划和允许自然增长的工作表 | 连续文档 | 明确分页的多页工作表 |
| `calculator` | 输入、计算和结果反馈工具 | 应用式输入区与结果区 | 独立结果摘要 |
| `report` | 多章节分析和审计成果 | 连续阅读 | 标准多页报告 |

不得为了复用 `.paper-a3` 而把四类工具伪装成同一种固定画布。每个工具完成迁移前必须在 `data/tool-design-contracts.json` 声明类型、屏幕模式和输出格式。

## 3. 不可突破的原则

1. **固定画布保持固定。** 桌面和打印不能用无限增高、内部滚动或内容截断掩盖容量问题。
2. **先设计内容容量。** 超量时依次精简内容、重组布局、调整纸张；不能以审计清零代替构图判断。
3. **画布只承载交付内容。** 工作流采用、证据管理和系统状态位于纸张外。
4. **单色优先。** 黑白打印不得丢失语义；颜色只能作为辅助编码。
5. **以静为美。** 直接编辑、低干扰反馈，不使用漂浮、弹跳和无业务含义的动效。
6. **三种呈现分离。** 桌面工作台、移动编辑和打印输出分别验收。移动端可以纵向重排，但不得被描述为纸张预览。
7. **用户控制数据。** 默认 local-first、无登录；项目正文不因目录、统计或主站集成离开浏览器。
8. **真实验收优先。** 无裁切只是最低门槛，不能替代纸张比例、层级、容量、可读性和实际 PDF 复核。

## 4. 纸张规则

- A3 横向用于复杂固定画布；A4 纵向用于简单固定画布和单页摘要。
- A4 横向不再作为新工具规格。历史页面若使用，必须迁移或登记例外。
- `fixed-canvas` 默认 `single-sheet`；确实需要多页时应改为 `worksheet` 或 `report`，而不是拉长纸张。
- 移动编辑模式不承诺物理比例；打印模式必须恢复合同指定的纸张规格和构图。

## 5. 结构边界

```text
工作台
├── 工具栏
├── 画布视口
│   └── 交付物
├── 工作流与证据面板
└── 状态、版本和帮助
```

新增系统能力时，先判断它是否出现在最终打印成果中。若答案是否定，禁止把它加入纸张容器。

## 6. 变更与验收

- 先迁移六个代表工具，再处理其余核心工具，最后处理扩展库。
- 固定画布必须验证空白、标准 fixture、允许的最长内容、桌面、移动编辑和实际 PDF。
- 计算器必须分别验证计算行为和结果摘要；报告必须验证分页和章节完整性。
- 自动化需检查合同覆盖、DOM 类型声明、固定画布比例和工作台/纸张边界。
- 视觉例外写入 `docs/DESIGN_DECISIONS.md`，不得以页面级 CSS 注释代替决策。
