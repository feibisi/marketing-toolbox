## 📌 产品定位

**当前定位**：营销方法论知识库 + 咨询交付工具箱

| 定位类型 | 描述 | 目标用户 |
|----------|------|----------|
| **知识库** | 营销方法论的可视化工具集合 | 学习者、研究者 |
| **咨询工具箱** | 顾问根据项目选择工具交付 | 咨询顾问、策略师 |
| **日常工作平台** | 营销人日常使用的工作软件 | 营销经理、运营人员 |

> ⚠️ 目前更偏向前两者，如果目标是"日常工作平台"，需要加入引导和筛选机制。

---

## 🎯 核心挑战

| 挑战 | 描述 | 优先级 |
|------|------|--------|
| **发现性差** | 用户不知道该用哪个工具 | P0 |
| **决策疲劳** | 太多选择导致学习曲线陡峭 | P0 |
| **维护成本高** | 100+ 工具的内容填充和更新工作量大 | P1 |
| **定位模糊** | 用户不清楚这是"工具集"还是"学习平台" | P1 |

---

## 📊 使用模式预测

根据帕累托法则（80/20原则）：

| 用户类型 | 预计使用工具数 | 说明 |
|----------|----------------|------|
| 普通营销人 | 15-20 个 | 日常工作需要 |
| 高级营销人/顾问 | 30-40 个 | 项目交付需要 |
| 专家级 | 50+ 个 | 完整方法论应用 |

**核心洞察**：
- 20% 的工具会被使用 80% 的时间
- 约 **25-30 个核心工具** 会成为主力
- 其余工具是"长尾"，偶尔用到

### 短期：分层设计

#### 入门级路径（10-15个核心工具）

- [ ] 标记"推荐"或"入门必备"标签

#### 进阶级路径（30-40个工具）

- [ ] 按使用场景分组
- [ ] 提供场景指南：
  - "做品牌战略时用这5个工具"
  - "做内容营销时用这8个工具"
  - "做数据分析时用这6个工具"

#### 专家级（全部工具）

- [ ] 作为完整工具库供查阅
- [ ] 强化搜索功能
- [ ] 添加标签和筛选器

### 中期：智能推荐

#### 场景化入口

```
用户选择："我要做品牌重塑"

系统推荐：
1. 品牌定位画布（必用）
2. 竞争格局地图（必用）
3. 品牌原型测试（可选）
4. 价值主张画布（可选）
```

#### 角色化定制

| 角色 | 主要工具类型 |
|------|-------------|
| CMO | 战略类工具 |
| 内容营销经理 | 内容 + 社交工具 |
| 增长黑客 | 数据 + 实验工具 |
| 品牌经理 | 品牌 + 定位工具 |

---

### 长期：从工具到平台

#### 工作流导向

不是"这里有100+个工具"，而是：
- "完成一次品牌战略规划"（引导用户用 5-8 个工具）
- "策划一场产品发布"（引导用户用 10-12 个工具）
- "建立内容营销体系"（引导用户用 8-10 个工具）

#### 模板化

- [ ] 提供"营销项目模板"
- [ ] 预设好一个项目需要用哪些工具
- [ ] 用户按流程走，不需要自己选

## 📚 参考案例

### Figma

功能很多，但通过以下方式降低认知负荷：
- 新手模板引导
- 按使用场景分类
- 社区分享最佳实践

### Notion

数据库、页面、模板无数，但：
- 模板库按场景分类
- 推荐"入门模板"
- 用户逐步发现高级功能

### Miro

几百个模板，但：
- 首页只展示最热门的 20 个
- 按行业/场景筛选
- 搜索功能强大

## [CX] 2026-08-13 稳定化后的产品方向

1. **核心集优先**：以 `data/tools.json` 的 30 个 core 工具作为支持面，144 个页面继续作为工具库；核心缺陷清零前不继续扩数量。
2. **工作流优先**：`data/workflows.json` 的 6 条路径是主入口，分别覆盖战略对齐、受众定位、品牌叙事、内容运营、获客成交、衡量增长。
3. **项目连续性**：先统一项目名称、品牌、负责人、目标和范围，再逐步为核心工具增加有类型的跨工具字段；不把所有 localStorage 字段无差别互联。
4. **证据可追踪**：下一阶段为核心工具增加“事实/假设/待验证”标识、来源和复核日期，再让报告生成器只汇总带来源的结论。
5. **质量先于协作**：保持 local-first 和可导出；多人协作、账户、云同步只在数据模型、权限和审计需求明确后另立项目。
6. **商业交付**：优先完善咨询方案包、品牌资产模板、UTM/线索/报价闭环和报告证据门禁，而不是增加同义画布。
