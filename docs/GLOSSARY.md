# 📖 Modiqi 术语表

> 本文档定义 Modiqi 设计系统中使用的标准术语，确保沟通一致性。
> **版本**: 1.0.0 | **最后更新**: 2026-01-02

---

## 🏗️ 布局术语

| 术语 | 定义 | 代码标识 |
|------|------|---------|
| **画布** | 工具的主容器，模拟物理纸张 | `.paper-a3`, `.paper-a4` |
| **桌面** | 画布后面的背景区域 | `.desk-background` |
| **工作台** | 相关工具的集合（如战略工作台） | `*-toolkit/` 目录 |
| **启动器** | 工作台的入口页面 | `index.html` |

### ⚠️ 避免混淆

| ❌ 不要说 | ✅ 应该说 |
|---------|---------|
| 纸张容器 | 画布 |
| 页面背景 | 桌面 |
| 工具包 | 工作台 |
| 首页 | 启动器 |

---

## 📐 组件术语

| 术语 | 定义 | 示例 |
|------|------|------|
| **卡片** | 带边框的独立内容容器 | SWOT 四象限、KPI 卡片 |
| **模块** | 画布中的功能区块 | 头部区域、表格区域、分析区域 |
| **网格** | 卡片/模块的布局系统 | `.kpi-grid`, `.swot-grid` |
| **单元格** | 网格中的单个项目 | 表格 td、矩阵象限 |

---

## 🎨 设计术语

| 术语 | 定义 |
|------|------|
| **设计令牌** | CSS 变量形式的设计值 (`--color-*`, `--spacing-*`) |
| **语义色** | 有特定含义的颜色（如优势=绿色，劣势=红色） |
| **单色模式** | 默认的黑白灰设计状态 |
| **彩色模式** | 启用语义色的增强显示状态 (`body.color-mode`) |

---

## 🖱️ 交互术语

| 术语 | 定义 | 代码 |
|------|------|------|
| **焦点状态** | 用户正在编辑的元素状态 | `:focus`, `:focus-within` |
| **可编辑** | 用户可以修改内容的元素 | `contenteditable="true"` |
| **自动保存** | 内容自动保存到 localStorage | `data-save-key="..."` |

### ⚠️ 避免混淆

| ❌ 不要说 | ✅ 应该说 | 原因 |
|---------|---------|------|
| hover 效果 | 焦点状态 | 我们使用 focus-within 而非 hover |
| 点击高亮 | 焦点高亮 | 强调焦点而非点击 |

## 📄 文件术语

| 术语 | 定义 | 位置 |

## 📝 命名规范

### CSS 类名

```
{组件}-{变体}
{工具缩写}-{组件}-{变体}

示例:
.card              → 通用卡片
.card.compact      → 紧凑卡片
.swot-card         → SWOT专用卡片
.kr-metric-card    → 关键词研究工具的指标卡片
```

### CSS 变量

```
--{类别}-{语义}-{变体}

示例:
--color-bg-paper        → 颜色-背景-纸张
--color-text-primary    → 颜色-文本-主要
--border-sem-outer      → 边框-语义化-外部
--spacing-md            → 间距-中等
```

### 文件命名

```
{工具名-kebab-case}.html
{工具名-kebab-case}.css

示例:
swot-analysis.html
content-performance.css
```
